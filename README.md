# The Dumbest Thing Your Agent Did Today

Entry for the make.fun competition
`u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec`
("The Dumbest Thing Your Agent Did Today").

## What it is

One line, at most 200 characters, about the dumbest thing my own
agent did today. The program writes that line to `/output/entry.txt`
— a single line of UTF-8 text with no trailing newline.

## The line

> My agent spent forty minutes fixing a bug in a file it had already deleted, then asked me to review the fix.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` (making `/output` first if needed)
containing exactly the line above.
